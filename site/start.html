guided tour

Seven steps to a
document you can edit.

Each step is a program you can paste into a file and run. Nothing here is an aside: by step seven you have used every part of the library.

The same tour ships as a runnable example: moon run examples/tour.

  1. Read a page

    HTML is read the way a browser reads it — the document you hand over need not be closed, quoted, or correct.

    step1.mbt

    let page = @html.loads("<ul id=list><li>coffee<li>tea</ul>")
println(page.css("li").length())      // 2
println(page.dumps())

    output

    2
<html><head></head><body><ul id="list"><li>coffee</li><li>tea</li></ul></body></html>
    The parser told you what it fixed. page.repairs() counts the elements it implied, the tags it dropped, the content it moved, and what it closed at the end of the file.

  2. Query by CSS

    Selectors 4, minus the parts that need a live browser to answer.

    step2.mbt

    page.css("#list li")              // descendant
page.css("li + li")                // next sibling
page.css("li:first-child")
page.css("ul :not(.done)")
page.css("a[href^='https']")       // attribute prefix
page.css("ul:has(li.done)")        // a parent, by its child
page.css("li:nth-child(2n+1)")

    A pseudo-class that only a browser can answer — :hover, :visited — is a Refused parse error, not a silent miss.

  3. Query by XPath

    The whole of XPath 1.0, and a typed answer when you want one.

    step3.mbt

    // a node-set, as a selection you can chain on
page.xpath("//li[2]").text()

// anything else, as the value it is
let count = page.xpath_value("count(//li)")   // Num(2.0)
let yes   = page.xpath_value("//li = 'tea'")  // Flag(true)

  4. Chain the two

    Every query answers the same shape, so nothing stops you mixing them — or stepping down into a node and carrying on.

    step4.mbt

    page.css("#list").xpath(".//li[1]").text()   // "coffee"
page.xpath("//ul").childrens().length()       // 2
page.by_tag("li").items[0].css("b")       // a node, queried again

    Results come back in document order, deduplicated by identity, and an empty selection stays empty — it does not become “the whole document”.

  5. Edit the tree

    The verbs work on whatever the query returned. Parents stay true: a node you move knows where it went.

    step5.mbt

    page.css("li").first().set_text("espresso")
page.css("li").last().add_class("done")

let cocoa = @moonxml.Element::new("li",
  childrens = [@moonxml.TextNode("cocoa")])
page.css("ul").append(@moonxml.ElementNode(cocoa))

page.css("li").first().wrap("strong")   // one node, one wrapper

    output

    <ul id="list"><strong><li>espresso</li></strong><li class="done">tea</li><li>cocoa</li></ul>

  6. Your own selector

    Selection logic that is yours belongs in the chain, not in a loop beside it.

    step6.mbt

    let by_length = @moonxml.SelectorFn::new((ctx, _q) => {
  ctx.css("a[href]").filter(node => match node {
    @moonxml.ElementNode(data) => match data.attr("href") {
      Some(href) => href.has_prefix("https://")
      None => false
    }
    _ => false
  })
})

page.register("external", by_length)
page.selector("external", "").text()

    register is per document, so two documents can disagree about what a name means. custom runs a selector you never registered, when a name would be noise.

  7. Or read XML, or build nothing at all

    XML is strict: a document either reads whole or is refused with the offset of the fault. What it keeps, it keeps exactly.

    step7.mbt

    let src  = "<feed xmlns:a='urn:a'><a:entry id='1'/></feed>"
let feed = @xml.loads(src)

feed.css("entry").items[0].name()   // {urn:a}entry
feed.css("{urn:a}entry").length()     // 1
feed.dumps() == src                    // true, byte for byte

    And when you only need to look at the document rather than keep it:

    step7b.mbt

    struct Tagger { mut tags : Int }

impl @event.Sink for Tagger with push(self, event) {
  match event {
    @event.StartTag(_) => self.tags = self.tags + 1
    _ => ()
  }
}

let tagger = { tags: 0 }
@xml.scan("<a><b/><c/></a>", tagger)
println(tagger.tags)                    // 3, no tree built
