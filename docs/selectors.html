08

What is not on this board

:hover, :active, :focus, :visited and :target describe a browser's state, not a document's, so the engine refuses them by name — @moonxml.Refused.BadQuery with the offset — instead of answering a question it cannot see. Everything a tree can settle is above; page.css("a:hover") is a sentence the library will not pretend to understand.
