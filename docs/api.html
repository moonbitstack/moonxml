pub fn named_reference(String) -> String?

The named character references HTML defines — all 2231 spellings of them, in the table the standard keeps, generated into entities_table.mbt. A name that may be written without its semicolon is in the table twice, so named_reference("amp") and named_reference("amp;") answer the same &. An unknown name answers None, which is the tokenizer's cue to leave the text as it stands.
